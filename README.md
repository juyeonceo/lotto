## ✨ 핵심 기능 (Key Features)

### 1. 👑 최고급 24K 골드 & 딥 옵시디언 VIP 디자인
- **인터랙티브 3D 볼 믹서 머신**: 실시간 물리 회전 연출 및 1구씩 순차 드롭 애니메이션
- **내장 Web Audio 신시사이저**: 외부 리소스 로딩 없는 무지연 골든 차임 & 잭팟 팡파레 사운드
- **24K 황금 볼 & 골드 컨페티**: 축하 금가루 파티클 및 럭셔리 모드 전환 지원

### 2. 📊 동행복권 역대 당첨 빅데이터 정밀 통계
- **최신 1,160회차 포함 실제 당첨 데이터셋** 내장
- 최다 출현 **HOT 넘버 TOP 10** vs 최저 출현 **COLD 넘버 TOP 10**
- 주기 도래 **장기 미출현 번호 TOP 10** (연속 미출현 주기 추적)
- **1~45번 전수 출현 빈도 매트릭스** 차트
- 홀짝 비율(3:3, 4:2, 2:4) 및 색상별(황금/청색/적색/회색/녹색) 분포, 황금 총합 구간(100~175) 통계

### 3. 🎯 5대 VIP 특화 알고리즘 엔진
1. **AI 퀀트 밸런스**: 역대 출현 가중치 + 홀짝 밸런스 + 총합 필터 + 3연번 방지
2. **골든 핫(HOT) 맹공**: 최근 다빈도 기세 좋은 번호 집중 추출
3. **역발상 콜드(COLD)**: 통계적 평균 회귀 이론에 따른 미출현 번호 조합
4. **운세 & 꿈 해몽 매직**: 황금 돼지꿈, 용꿈, 조상님 꿈 등 길몽/사주 키워드 해시 생성
5. **마스터 커스텀 필터**: 고정수(최대 5개), 제외수, 총합 구간, 홀짝 비율 직접 커스텀

### 4. 📈 과거 50주 실제 당첨 데이터 백테스팅 시뮬레이터
- 현재 조합으로 과거 실제 회차에 매주 투자했을 때의 당첨금, 투자 수익률(ROI), 최고 등수(1~5등) 실시간 추적

### 5. 💎 5게임 VIP 공식 슬립지 & 24K 황금 인증서
- 실제 대한민국 로또 5,000원 슬립지(A, B, C, D, E) UI
- 브라우저 로컬 스토리지 암호화 VIP 티켓 보관함
- 고유 시리얼 넘버가 포함된 인쇄/공유용 24K VIP 황금 복권 인증서

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Audio & Effects**: Web Audio API (Synthesizer), Canvas Confetti
- **Typography**: Pretendard Font
